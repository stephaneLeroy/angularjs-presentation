CLI d'Anthropic — un coéquipier dans votre terminal

Pas un autocomplete. Un agent autonome.

Il comprend, planifie, exécute, vérifie, itère.

Installation

$ npm install -g @anthropic-ai/claude-code
$ cd mon-projet
$ claude
C'est tout. Pas de config, pas de setup.

Parallélisme

/batch Orchestre des sub-agents en parallèle (1 terminal, safe)
Sub-agents Workers isolés dans la même session
Agent Teams Plusieurs terminaux, task list partagée, messages peer-to-peer

Bonne pratique : séparer les fichiers par agent pour éviter les conflits

Les Hooks

Vos garde-fous automatiques

{
  "hooks": {
    "PreToolUse": [{ "command": "lint" }],
    "PostToolUse": [{ "command": "test" }],
    "Stop": [{ "command": "notify" }]
  }
}

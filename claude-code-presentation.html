CLI d'Anthropic — un coéquipier dans votre terminal

Pas un autocomplete. Un agent autonome.

Il comprend, planifie, exécute, vérifie, itère.

Installation

$ npm install -g @anthropic-ai/claude-code
$ cd mon-projet
$ claude
C'est tout. Pas de config, pas de setup.
Démo 1

/init & CLAUDE.md

La mémoire du projet : conventions, architecture, règles.
Se charge automatiquement à chaque session.
claude> /init
# Analyse le projet, crée CLAUDE.md

claude> /memory
# Voir et éditer la mémoire persistante
/init CLAUDE.md /memory
Glisser un /btw "c'est quoi la diff entre CLAUDE.md projet et user ?" pour montrer les questions en aparté sans polluer le contexte.
